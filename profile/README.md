# NeoVoxel 开发团队

## 🚀 关于我们

欢迎来到 NeoVoxel 开发团队, 我们团队致力于打造 Minecraft Java 版相关的一些作品 (如 Spigot 插件, Fabric 模组), 为玩家提供更好的游玩体验

我们欢迎更多开发者加入我们, 如有意愿可以通过下方联系方式来联系我们!

## 💡 技术栈

- **开发语言**: 
  - **Java**
  - Go
  - Vue
- **开发框架**:
  - Spigot/Velocity 等插件 API
  - VitePress
  - Wails
- **数据库**: 
  - MySQL
  - MariaDB
  - PostgreSQL
  - SQLite
  - H2
